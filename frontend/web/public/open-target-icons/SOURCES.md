# Open-target icon sources

These images identify applications that Termestra can open. They are not
Termestra branding and their use does not imply sponsorship or endorsement.
Product names, icons, and trademarks belong to their respective owners.

- `vscode.png`: Microsoft Visual Studio Code approved blue brand icon from
  <https://code.visualstudio.com/brand>.
- `intellij-idea.png`: extracted from the IntelliJ IDEA application bundle
  installed by JetBrains on macOS.
- `cursor.png`: Cursor 2.5D dark application icon from the official brand asset
  archive at <https://cursor.com/brand>.
- `ghostty.png`: Ghostty application icon from the official repository,
  <https://github.com/ghostty-org/ghostty/blob/main/images/icons/icon_256.png>.
- `zed.png`: Zed application icon from the official repository,
  <https://github.com/zed-industries/zed/blob/main/crates/zed/resources/app-icon.png>.
- `finder-mac.png`: extracted from the Finder application bundled with macOS.
- `terminal-mac.png`: extracted from the Terminal application bundled with
  macOS.
- `finder-windows.svg`: Microsoft Fluent folder system icon from
  <https://github.com/microsoft/fluentui-system-icons>.
- `finder-linux.svg`: GNOME Files application icon from
  <https://github.com/GNOME/nautilus>.
